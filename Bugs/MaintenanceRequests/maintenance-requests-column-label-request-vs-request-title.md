# Bug Report Template

## Title

The "Request" column header should say "Request Title" for clarity

## Summary

On the Maintenance Requests list page, the first column in the table is labeled just "REQUEST". This column actually shows the request's title (e.g. "Keys issue"), but the plain word "Request" doesn't make that clear at a glance — it could just as easily be read as an id, a type, or a category. Renaming it to "Request Title" would remove the ambiguity.

## Description

### Steps to Reproduce

1. Log in to the Admin Panel.
2. Go to the Maintenance Requests page.
3. Look at the first column header in the table.

### Actual Result

The column header reads "Request".

### Expected Result

The column header should read "Request Title", making it immediately clear what the column contains.
